# MYBRAND

좋아하는 브랜드만 모아 탐색하고 쇼핑하는 개인화 패션 쇼핑몰 프로토타입입니다.

## 주요 기능

- 브랜드 및 카테고리 필터
- 상품 검색과 가격 정렬
- 찜 목록과 장바구니
- 상품 상세 모달
- 반응형 모바일 UI
- 브라우저 로컬 저장

## 로컬 실행

`dist` 폴더를 정적 HTTP 서버로 실행한 뒤 브라우저에서 접속합니다.

```bash
npx serve dist
```

## 구조

- `dist/index.html` — 화면 구조
- `dist/styles.css` — Pretendard 기반 다크 글래스 UI
- `dist/app.js` — 검색, 필터, 찜, 장바구니 동작
- `dist/assets` — 패션 이미지 에셋
